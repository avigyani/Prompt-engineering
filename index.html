A taste of the advanced level

Weak prompt: "Write code for a login page." Advanced prompt: "Act as a senior front-end developer. Build a responsive login page in a single HTML file: email + password fields, show/hide password toggle, inline validation messages, and a disabled submit button until the form is valid. Use semantic HTML and CSS only, no frameworks. After the code, list 3 accessibility improvements I should add next, in order of impact."
Weak prompt: "Summarise this long report." Advanced prompt: "Summarise this report in exactly 5 bullet points, each under 20 words. Point 1: the single most important finding. Points 2–4: the three numbers that support it, with their values. Point 5: the one action the reader should take this week. If any number is missing from the report, write 'not stated' instead of guessing."
